# Language (VI / EN)

## Behaviour

- Cookie: `tasco-locale` (`vi` default, `en` if value is exactly `"en"`).
- Toggle: `demo/src/components/language-toggle.tsx` in both shells. Calls `switchLocale` (`demo/src/app/actions/locale.ts`).
- `switchLocale` sets the cookie, `revalidatePath("/", "layout")`, and if the user is a **customer**, writes `customer.preferredLanguage`.
- `/api/chat` also copies the cookie onto `preferredLanguage` on every request so demo/LLM replies match the UI even if the customer record was stale.
- `<html lang={locale}>` in `demo/src/app/layout.tsx`.

## Dictionaries

`demo/src/lib/i18n/dictionaries.ts` — parallel `vi` / `en` objects. `Dictionary` is `DeepStringify<typeof vi>` so the two trees can differ in literal strings.

Usage on server pages:

```ts
const locale = await getLocale();
const dict = getDictionary(locale);
```

Pass `locale` (and `dict.chat` labels) into client components that cannot call `cookies()`.

Helper `demo/src/lib/i18n/t.ts` exists for dotted keys if needed; most screens use `dict` directly. Use `format(dict.x.y, { n })` for `{placeholder}` strings.

## When you add a screen

1. Add keys to **both** `vi` and `en` in `dictionaries.ts` (same shape).
2. Read `getLocale()` / `getDictionary()` in the server page for titles.
3. Pass `locale` into client widgets.
4. Add a VI + EN entry for the route in `demo/src/lib/page-tours.ts` so the Tour button explains the page.
5. If the screen talks to the agent, do not introduce a second language toggle (Classic chat used to have a local `Lang:` button; that was removed in favor of the global header).
6. Keyword handlers in `demo-reply.ts` must accept **both** Vietnamese and English chips (`xác nhận` / `confirm`, `thanh toán` / `pay`, `nhân viên` / `human`, `gia hạn` / `renew`).

## Runtime data (scores, handovers, audit, triage, workflow maps)

Never store a finished English sentence in the session. Store a code + params and render it per locale:

- `demo/src/lib/i18n/generated.ts` — `describeReason`, `describeNextAction`, `describeHandover`, `describeAudit`, `describeTriage`. New `appendAudit` actions: pass `params` and add a template to `AUDIT` (the `detail` string is only the English fallback).
- `demo/src/lib/workflow/i18n.ts` — VI text for workflow nodes/transitions, process steps/lanes, schema descriptions/relations (the source files stay English).

## Office vs dictionary

JRPG station intros stay in `office-copy.ts` so the 2D layer is self-contained. Shell/nav stay in dictionaries. Do not duplicate the same sentence in both unless it is truly shared.
